OpenJobAutofill

维护本机简历资料

数据只保存在本机浏览器里，不会走同步云端。AI 只辅助识别表单字段和可匹配的资料项，不会读取你的简历值。点击开始填写后会自动填写能确定的字段，待处理字段可在资料面板查看和手动复制。

首次使用

三步开始网申填写

  1. 填写资料 先在下面按模块维护本机简历资料。
  2. 保存资料 点击底部“保存资料”，看到浮层提示后就已保存到本机。
  3. 开始填写 打开招聘表单页，点击插件图标里的“开始填写”。

AI 页面分析默认走内置的内网本地代理（开箱即用，只发送字段名、不发送资料值）；如需更换，到下方 API 设置修改后点“保存 API 设置”。完全不配置 API 时也可使用本地规则填写。

资料目录

简历资料

这里按通用网申栏目拆开填写。保存后资料只保存在本机浏览器里，需要迁移或备份时再导出资料备份。

从简历导入（AI 解析）

粘贴简历全文，或选择 .txt / .md / .html / .pdf 文件（例如在线简历页“另存为”的 HTML、简历 PDF）。AI 会把简历结构化为资料栏目，合并进下方编辑器供你复核，确认无误后再点“保存资料”。

隐私提示：与页面填写“只发字段名”不同，本功能会把简历原文发送到你配置的 AI 接口做一次性解析，请先确认已保存 API 设置。

资料加载后，编辑任意字段会在这里提示是否需要保存。

版本更新

插件会定期检查 GitHub Release。发现新版本时，浏览器图标会显示 NEW；更新前建议先导出资料备份。更新时不要卸载扩展，覆盖或重新加载后，本机资料和 API 设置会保留。

API 设置（用于 AI 页面分析与简历解析）

默认已配置内网本地代理（127.0.0.1:15721，模型 glm-5.3-flash），开箱即用；也可以改成任意 OpenAI 兼容接口或自定义请求模板。

可用变量：{{modelJson}}、{{messagesJson}}、{{systemPromptJson}}、{{userPromptJson}}、{{profileJson}}、{{profileCatalogJson}}、{{fieldsJson}}、{{scanJson}}。其中 profile* 变量都是本地字段目录，不含具体值。
